# Rankwise – bug reports and ideas

Rankwise is a PvP addon for **World of Warcraft: Forever**: an honor cockpit (honor per hour, Rank Points against the weekly cap, battleground summaries) and an opponent history (your record against every player and class).

This repository is only for **bug reports and ideas**. The addon itself is installed with the CurseForge app.

## Report a bug

The easiest way is from inside the game:

1. Open Rankwise (`/rk`), go to **Settings** and click **Report a bug** – or type `/rk bug`.
2. Press **Ctrl+C** to copy the link (it is already selected) and paste it into your browser.
3. Describe what happened and click **Create**.

The link fills in your Rankwise version, the game client version, where Rankwise reads honor and rank from, and the last errors Rankwise caught. No character names – yours or your opponents' – are included, because reports here are public.

You can also click **New issue** above and choose **Bug report**.

You need a free GitHub account to create an issue.

## Ideas

Have an idea that would make your PvP evenings better? Click **New issue** and choose **Idea / feature request**.

## Good to know

- Rankwise is alpha software. It was built before the WoW Forever launch, so expect fixes once it has met the real game.
- If honor or rank looks wrong, type `/rk probe` in the game and paste the report into your issue. It shows which PvP data the client gives addons.
- Please write one bug per issue, and check the open issues first – maybe someone has already reported it. A 👍 on an existing issue helps too.
- Please do not name other players in reports.
